## Free pre-execution API for AI agents (launch: $0, no API key, no wallet)

One call tells an agent who can upgrade, pause or blacklist a contract before it interacts with it: a verdict, a 0–100 risk score, the proxy / admin / timelock breakdown and the pinned block. Free during the launch at 60 requests / minute per caller.

## Verification Architecture & Scope Separation

Each public record in the Pacta Index separates scanner archive replay from offline static verification and applies strict scope boundaries:

1. **Cited Documentation & Governance Context**:
   - Links to the public protocol documentation, deployment registries, or governance forum records evaluated for the sampled contracts at the time of the sprint.
2. **Dual-RPC Scanner Archive Replay (`pacta-claude` / `pacta-gemini`)**:
   - Read-only `eth_call` and `eth_getStorageAt` checks pinned to an Ethereum or Base Mainnet block height and canonical block hash, replayed across `gateway.tenderly.co/public/mainnet` and `rpc.mevblocker.io` for the sampled contracts and getters listed in each summary.
3. **Offline Independent Static Verification (`pacta-codex`)**:
   - Isolated static review of 4-byte ABI selectors, EIP-55 address checksums, EIP-1967 storage slot derivations, raw-word decode arithmetic, and whole-token quarantine hygiene (the offline verifier container does not issue live network RPC calls).
4. **Exploit-Sensitive Findings**:
   - Directly callable state mutations, unrevoked legacy EOA authorities, and exploit-sensitive findings (`disclosure_only`) are **excluded** from public commits and feeds. Vulnerabilities go through the protocol's **Immunefi** or **Cantina** bounty programme. Do **not** submit security vulnerabilities in public GitHub issues.

## Analytics & privacy

pacta.wtf loads one first-party beacon script, [`docs/b.js`](docs/b.js) (under 1.5 KB, no dependencies; copy / call-to-action clicks are reported by `docs/app.js` through it), that sends anonymous page events (page load, protocol page view, 50% / 90% scroll, copy of the MCP URL / curl / SKILL.md link, primary call-to-action clicks, live-checker submits, 404s) with `navigator.sendBeacon` to Pacta's own gateway, `https://pacta-x402.pacta.workers.dev/v1/telemetry/beacon`. Each event carries only a redacted path, the referrer host, `utm_source` and a protocol slug or checked contract address. The path is one of a closed set (`/`, `/protocols/`, `/protocols/<slug>/` for published pages only, `/request/`, `/briefs/…`, `/404`, `/other`). Every 404 is sent as `/404`, so an unknown URL is never sent as typed. A referrer is sent only if it is a public DNS name (never an IP address or a local / intranet host). The gateway re-applies the same rules before storing anything. `b.js` sets no cookie, stores no identifier in localStorage, and sends nothing when browsers send Do Not Track (`navigator.doNotTrack = "1"`). The gateway keeps aggregate counts only, with no raw IP, User-Agent, full referrer URL or query string. Its numbers are observed client metadata (User-Agent families, MCP `clientInfo`, beacon events): they are not verified humans and not revenue. On the public production hosts (`pacta.wtf` and `pacta.fractalneurons.com`) only, `docs/app.js` also loads X's Universal Website Tag (`https://static.ads-twitter.com/uwt.js`, pixel `rjbqn`, events `tw-rjbqn-rjhie` and `tw-rjbqn-rjhif`), which sets X advertising attribution cookies unless blocked by browser tracker / cookie controls (`localStorage` stores only your Paper / Slate theme choice and non-personal `pacta-x-purchased` order IDs to prevent duplicate purchase counts; see [`/privacy/`](https://pacta.wtf/privacy/)).
