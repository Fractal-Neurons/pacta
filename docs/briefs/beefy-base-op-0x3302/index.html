4. Risk Notes

  • setDeviation(25) widens the strategy's calm check from 9 to 25 ticks: how far the current pool tick may sit from its 120 s TWAP before the strategy refuses to act. The pool's tick spacing is 50. This is a looser price-manipulation guard on the USDC-VVV pool, not a code change.
  • At the pinned block isCalm() = true, with the tick (246,120) 1 ticks from the TWAP (246,121). The flag moves with price; after execution, moves of up to 25 ticks from the TWAP still count as calm.
  • The strategy is a beacon proxy. Its implementation (0xde4e9b0e287c38d0a8cc53ade899edb159827bf1) is not verified on Sourcify, though setDeviation, maxTickDeviation and isCalm are confirmed in its dispatch table. The beacon (0x883dda584b6d4367a26f897d7bfc3e6f5dd9c7a1) is controlled through Beefy's StrategyFactory (verified on Sourcify), which this timelock owns: implementation swaps also wait for the 21,600 s delay.
  • This is not a strategy upgrade: the selector is setDeviation(int56), not upgradeStrat(), and the vault keeps the same strategy.
