1. Findings

  • One 2-of-3 Safe, 0x9040…EeD4 (getThreshold() = 2), is governorAdmin() of the USDC vault, governor() of the EulerRouter (= 0x9040…EeD4) and holds DEFAULT_ADMIN_ROLE on efixDI+. No TimelockController sits between that Safe and these contracts, so the router's oracle configuration, LTVs and caps can be changed by one executed 2-of-3 Safe transaction, with no enforced on-chain delay.
  • The router prices efixDI+ through the custom adapter 0x9CD2…7788 (name() = “efixDI/USDC par x ChainlinkBRLUSD”). Borrow / liquidation LTV 70% / 77%, interest fee 15%.
  • Supply cap 3,440.00 USDC, borrow cap 23,000.00 USDC; total assets 3,480.37 USDC, borrows 3,135.58 USDC (90.1% utilization).
  • MINTER_ROLE on efixDI+ is held directly by 0x8f8C…CCb1, an account with no contract code (0 bytes) and 1,159 transactions sent, which is also one of the three signers of the governor Safe. Calls gated only by MINTER_ROLE need no second signature and no delay.
  • efixDI+ AccessControl role history (19 events, blocks 41,724,585–57,050,397): DEFAULT_ADMIN_ROLE → 0x9040…EeD4 (2-of-3 Safe); PAUSER_ROLE → 0x9040…EeD4 (2-of-3 Safe); MINTER_ROLE → 0x8f8C…CCb1 (EOA, 1,159 txs, signer of 0x9040…EeD4).
  • EFIX.owner() = 0x7C54…7537: an EOA carrying an EIP-7702 delegation designator to 0xdf02…8792, 156 transactions sent. It is not a Safe or a timelock.
