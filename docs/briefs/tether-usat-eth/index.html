1. Findings

  • USAT 0x0704…8b68 is an EIP-1967 proxy: implementation 0x8B98…4d0e, ProxyAdmin 0x3e4C…d9C7 whose owner() is 0x62b3…c5Cb. USAT.owner() is the same address.
  • That controller is a legacy MultiSigWallet (submit / confirm / execute; 5,705 bytes), required() = 3 of 5 owners. It is not a TimelockController: an upgrade or owner action executes as soon as the third confirmation lands.
  • Linked queue: Ethena timelock 0xE8Dc…7c94 (86,400s delay) holds two pending operations (isOperationPending = true / true) that add RLUSD and USAT to EthenaMinting; the USAT operation becomes executable at 2026-11-14 10:22:23 UTC. See the Ethena pre-execution brief.
  • The forum thread assesses the bridged USAT on Avalanche; this brief covers the canonical Ethereum token whose redemption and credit exposure that bridged asset inherits.
