4. Risk Notes

  • One scheduleBatch of 5 AssetRouter calls whose predecessor is operation 0xceeeff86…18eb, the AssetRouter upgrade; it executed at block #26,440,758 (isOperationDone = true at the pin), so the batch is executable from its ETA.
  • minRequestAmount (the router-wide minimum for a swap or a non-BTC redeem) doubles from 2,000 sats to 4,000 sats. It is set first in the batch: the router keeps the highest deposit fee at most half of the minimum.
  • LBTC and BTC.b each get a fixed deposit fee of 2,000 sats on every proof mint, minted to the token's treasury (both 0 sats at the pin): exactly half of the new minimum, and above the 100 sats–1,000 sats range an OPERATOR_ROLE holder may set, so only the timelock can set it.
  • LBTC redeems not bound for Bitcoin stop paying redeemFee (10,000 sats to 0 sats), while LBTC redeems to Bitcoin start paying toNativeCommission (0 sats to 10,000 sats).
  • The 3-of-5 Safe 0x251a…4892 (Safe 1.3.0) that scheduled the batch is this timelock's proposer, canceller and executor; the executor role is not open. The timelock is the AssetRouter's owner() and defaultAdmin() (defaultAdminDelay 0 s) and holds no OPERATOR_ROLE.
