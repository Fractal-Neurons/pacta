4. Risk Notes

  • Both core proxies, UmiaHub and UmiaMarketCore, are upgraded in the same batch; the queued implementations are verified on Sourcify v2 (match), as are the current ones.
  • Three new periphery contracts are not verified on Sourcify v2 at the pin: the conditional-market oracle, the spot migrator and the LBP strategy factory.
  • The activeLiquidityKeeper role goes to an address with no code (an externally owned account): once executed, one key holds that role.
  • spotMigrator(), activeLiquidityKeeper(), launchAnchorBps() and launchActiveHalfWidthTicks() revert on the current implementation; they exist only after call 1 upgrades UmiaHub, so the batch only works as one unit.
  • The timelock contract is not verified on Sourcify v2; getMinDelay() reads 172,800 s (48 hours) on both RPC endpoints, and the operation is executable from 2026-11-23 10:30:40 UTC.
