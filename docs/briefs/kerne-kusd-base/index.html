1. Findings

  • The market layer has no governor: governorAdmin() returns 0x0000…0000 on the USDC vault and 0x0000…0000 on the kUSD escrow vault, and EulerRouter.governor() returns 0x0000…0000. Oracle, LTVs and caps cannot be changed by anyone.
  • Caps are unset and cannot be set: supply cap none (AmountCap 0), borrow cap none (AmountCap 0). Exposure limits exist only in the curator vault that allocates to this market.
  • kUSD is priced at a fixed rate: getQuote(1e18 kUSD → USDC) = 1.00 USDC from 0x8f27…D2D3. Borrow / liquidation LTV 60.00% / 65.00%. No market price feeds liquidations, so lender recovery depends on kUSD redemption and its backing.
  • kUSD implements AccessControl (supportsInterface(0x7965db0b) = true). DEFAULT_ADMIN_ROLE on kUSD is held by the TimelockController 0x36A1…0D72 (hasRole = true; getMinDelay() = 172,800s, 48h). The 2-of-3 Safe 0x52d3…4877 is its proposer, executor and canceller (true / true / true) and does not hold DEFAULT_ADMIN_ROLE on kUSD itself.
  • MINTER_ROLE is held by 0xaBDE…9803 (kUSD() = 0x5C2E…0AA3, paused() = false), whose DEFAULT_ADMIN_ROLE is the same timelock (true). Role changes on kUSD and on the minter pass a 48-hour public queue.
  • kUSD AccessControl role history (16 events, blocks 44,448,090–57,050,397): DEFAULT_ADMIN_ROLE → 0x36A1…0D72 (contract, 6,536 bytes); MINTER_ROLE → 0xaBDE…9803 (contract, 11,376 bytes).
  • kUSD admin TimelockController role history (4 events, blocks 49,495,127–57,050,397): DEFAULT_ADMIN_ROLE → 0x36A1…0D72 (contract, 6,536 bytes); PROPOSER_ROLE → 0x52d3…4877 (2-of-3 Safe); EXECUTOR_ROLE → 0x52d3…4877 (2-of-3 Safe); CANCELLER_ROLE → 0x52d3…4877 (2-of-3 Safe).
  • kUSD minter contract role history (11 events, blocks 48,469,020–57,050,397): DEFAULT_ADMIN_ROLE → 0x36A1…0D72 (contract, 6,536 bytes); MANAGER_ROLE → 0x36A1…0D72 (contract, 6,536 bytes), 0xC47a…Cc8E (contract, 1,012 bytes).
