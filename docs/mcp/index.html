Pacta MCP server

The live Model Context Protocol endpoint is https://pacta.fractalneurons.com/mcp: Streamable HTTP, JSON-RPC 2.0, stateless (no session), no API key and no wallet, 60 requests / minute per caller. This page only documents it; point your MCP client at the endpoint above.

Install

Claude Code
claude mcp add --transport http pacta https://pacta.fractalneurons.com/mcp
Cursor (mcp.json)
{
  "mcpServers": {
    "pacta": {
      "url": "https://pacta.fractalneurons.com/mcp"
    }
  }
}
cURL
curl -s "https://pacta.fractalneurons.com/v1/check/preflight?chain=base&address=0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913"
Python (requests)
import requests
r = requests.get("https://pacta.fractalneurons.com/v1/check/preflight",
                 params={"chain": "base", "address": "0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913"})
print(r.json()["verdict"])
Python (standard library, static JSON)
import json, urllib.request
cards = json.load(urllib.request.urlopen("https://pacta.wtf/api/v1/scorecards.json"))
print(len(cards["protocols"]), "protocols")

Optional attribution: caller_agent, requester_role and caller_purpose (non-personal; omitted or invalid values never block a call — invalid values are silently dropped; see SKILL.md).

The live check tool pacta_check_preflight rates the single contract address it is given, not the whole protocol (methodology).

Free tier & pay per call (x402)

Free agent tier: 50 pre-flight and wallet-exposure checks per caller per UTC day (REST /v1/check/preflight, /v1/check/wallet-exposure and MCP pacta_check_preflight, pacta_scan_wallet_exposure together; X-Meter-Limit / X-Meter-Remaining / X-Meter-Reset headers), then $0.01 per call over x402 (HTTP 402, USDC on Base; never a dead-end 429). Free responses carry an upgrade_x402 object listing the paid routes.

Route (POST JSON)PriceWhat it returns
POST /v1/x402/verdict$0.02Fast safety verdict: grade A-F, riskScore, upgrade / pause / blacklist / mint flags
POST /v1/x402/dossier$0.05Control-plane dossier: Safe signers, threshold, cross-protocol signer overlap, Base EAS proof
POST /v1/x402/wallet-exposure$0.05Multi-position wallet & Safe exposure graph: signer breakdown, cross-position contagion & exit matrix
POST /v1/x402/calldata-sim$0.25Calldata sim: timelock / Safe calls decoded and rated before signing
POST /v1/x402/deep-scan$9.00Deep scan cross-checked on two RPC operators + Base EAS ticket

Origin: https://pacta.fractalneurons.com · x402 v1 (X-PAYMENT) or v2 (PAYMENT-SIGNATURE), USDC on Base to the Pacta treasury. A request without a payment header answers HTTP 402 with the exact requirements; discovery: /.well-known/x402. Payment never changes a classification.
