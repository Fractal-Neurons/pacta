Editorial independence & security

Does paying $500 or $2,500–$5,000 guarantee an ALIGNED badge?
No. Payment covers expedited engineering review and the Base EAS attestation only. The status strictly reflects what finalized on-chain state and the public documentation show.
We fixed our docs (or rotated signers). Can we notify Pacta for free?
Yes. Submit the updated docs commit or URL through /request/ at $0 for the community re-scan queue, or use the $500 Rapid 24h Single-Gap Re-Verification for a same-day re-attestation.
Do we need to share private keys, grant repo access or connect a wallet?
Never. Every scan is read-only against finalized public archive blocks and public documentation; invoices settle by standard invoice or Base USDC.
What if a finding exposes an active security vulnerability?
Pacta quarantines exploit-sensitive paths privately under coordinated disclosure (/.well-known/security.txt) and never publishes exploit primitives in public scorecards.
