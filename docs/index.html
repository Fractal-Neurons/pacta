05 / FAQ & Guardrails

Zero-noise engineering & strict disclosure ethics.

How do you protect sensitive security findings?

Any finding involving fund risk, privilege escalation, or freeze/DoS is strictly quarantined as disclosure_only. Zero exploit details appear in public PRs or web pages; they are routed exclusively via Immunefi/Cantina or official security emails.

What are your GitHub PR anti-spam guardrails?

Maximum 2–3 external PRs per day, minimum 2–4 hours spacing, maximum 1 open unmerged PR per target organization, zero cold @mentions, and zero commercial invoice pitches inside PR bodies.
