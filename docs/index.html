How it works

Three steps for every protocol, and two ways to use the result.

  1. 1

    Read the docs

    We record what each protocol publishes about who can upgrade, pause or change its contracts, and how long changes must wait.

  2. 2

    Read the chain at a finalized block

    We read the live contracts at a finalized block on two independent RPC providers: owners, multisig quorums, timelock delays and roles.

  3. 3

    Attest the difference on Base

    Each result is attested on Base with EAS, so anyone can re-check it later with one command.
