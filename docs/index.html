How Self-Serve Repo Verification Works (3 Steps, Zero SaaS Signup)

1. Point Pacta at Your Repo & Docs

Click Initiate Scan on My Repo (opens a structured 3-field GitHub Issue on Fractal-Neurons/pacta) or tag @pacta-fractal-neurons on your deployment/upgrade PR with your docs URL and contract registry path.

2. Automated Dual-Proof Scan + Independent Replay

Pacta extracts every parameter, role, timelock, and guardian promise from your docs/audits/proposals and runs deterministic archive-RPC probes (capability_holders, RolesAuthority 256-role bitmasks, Safe storage slots, and historical tx_receipt logs), verified by an independent replay node.

3. Receive Upstream PR + Turnkey Safe Remediation Batch

Non-sensitive drift is delivered as a clean upstream PR aligning your docs/configs. Sensitive access-control findings are quarantined for private handoff alongside ready-to-sign Gnosis Safe Transaction Builder JSON batches and a Foundry CI regression suite.

Drop-In Repo Config (.github/ISSUE_TEMPLATE/request-scan.yml)

When a protocol clicks Initiate Scan on My Repo, GitHub presents this structured intake form that automatically wakes the Pacta verification pipeline:

name: "Initiate Pacta Commitment-to-Chain Scan"
description: "Request an automated block-pinned verification of your live contracts against your docs, audits, and governance proposals."
title: "[Scan Request] <Protocol Name> — <Target Repo>"
labels: ["scan-request", "pacta-intake"]
body:
  - type: input
    id: repo_url
    attributes:
      label: "1. Target Smart Contract GitHub Repository"
      placeholder: "https://github.com/your-org/your-contracts"
    validations:
      required: true
  - type: textarea
    id: commitments_and_addresses
    attributes:
      label: "2. Documentation / Governance Spec URL & Mainnet Contract Registry"
      placeholder: "Docs: https://docs.yourprotocol.xyz\nChain & Addresses (or path to deployments.json): Ethereum Mainnet 0x..."
    validations:
      required: true
  - type: dropdown
    id: package_tier
    attributes:
      label: "3. Requested Verification Tier"
      options:
        - "Tier 1 ($0 USDC) — 1-Contract Baseline Drift Check PR"
        - "Tier 2 ($750 USDC Paid-at-Handoff) — Full Control-Chain Audit + Gnosis Safe Remediation JSON Batch + Foundry CI Suite"
        - "Tier 3 ($2,500 USDC/mo) — Continuous Pre-Flight Proposal & Curator Fleet Gate"
    validations:
      required: true
  - type: input
    id: security_contact
    attributes:
      label: "4. Maintainer Handle / Private Security Contact (for quarantined disclosure_only findings & Safe JSON delivery)"
      placeholder: "@github-handle or security@yourprotocol.xyz"
