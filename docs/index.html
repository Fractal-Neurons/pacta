04 / Verification & Quarantine Standards

Deterministic archive proofs & zero-leakage ethics.

How does Pacta separate public counterparty metrics from private security disclosures?

Any finding involving callable privilege escalation, unrevoked legacy EOA authority, or freeze/liveness exposure is quarantined under 0600 local storage as disclosure_only. Zero exploit paths, private EOA labels, or sensitive selectors appear in this index; they are transmitted strictly via GitHub Private Security Advisories, Immunefi/Cantina, or official security@ channels at $0 cost.

How can risk curators reproduce an index entry independently?

Every entry in /api/v1/index.json and audits/sprint-1..11 includes the exact contract address, function selector or EIP-1967 storage slot, and canonical Ethereum Mainnet block height + block hash, reproducible with a single cast call or cast storage against any archive node.
