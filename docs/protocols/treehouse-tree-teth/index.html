Treehouse (TREE / tETH): control-plane safety record

3 indexed control-plane surfaces for Treehouse (TREE / tETH), each pinned to a canonical Ethereum block and compared with what the protocol documents. Contracts: 0x2225…467e, 0x7714…d1f3, 0xD11c…5ED8

What differs

TREE transfer blacklisting: no enforced delay; TREE and tETH owner paths retain five-day timelocks (#26,440,048)

Treehouse's Timelock documentation states that all Treehouse contracts are secured by a 5-day timelock so no critical action executes immediately, while Pacta recorded at Ethereum block 26,440,048 that a 5-of-7 Safe holds blacklister() on the TREE token with no enforced delay; TREE upgrade ownership (#26,406,106) and tETH ownership (#26,407,707) retain 5-day TimelockControllers.

Matched

  • tETH owner() = 5d TimelockController: matches the documentation
