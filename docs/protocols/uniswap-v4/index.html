Check it live (free)

The pre-flight API re-reads the controller, proxy and capabilities of one contract at the latest block. No key, no wallet. The score rates that single contract, not the whole protocol.

cURL
curl -s "https://api.pacta.wtf/v1/check/preflight?chain=ethereum&address=0x000000000004444c5dc75cB358380D2e3dE08A90"
Python (requests)
import requests
r = requests.get("https://api.pacta.wtf/v1/check/preflight",
                 params={"chain": "ethereum", "address": "0x000000000004444c5dc75cB358380D2e3dE08A90"})
print(r.json()["verdict"])

Editorial independence

We do not publish ratings of protocols, and nobody can pay to change a result. Payment never alters a Pacta classification. A status changes when onchain contract state or public documentation changes and is verified at a new finalized block — or immediately and free of charge whenever Pacta corrects an overstatement or scoping error in its own comparison.
