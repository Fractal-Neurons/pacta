Check it live (free)

The pre-flight API re-reads the controller, proxy and capabilities of one contract at the latest block. No key, no wallet. The score rates that single contract, not the whole protocol.

cURL
curl -s "https://api.pacta.wtf/v1/check/preflight?chain=ethereum&address=0x3D18480CC32B6AB3B833dCabD80E76CfD41c48a9"
Python (requests)
import requests
r = requests.get("https://api.pacta.wtf/v1/check/preflight",
                 params={"chain": "ethereum", "address": "0x3D18480CC32B6AB3B833dCabD80E76CfD41c48a9"})
print(r.json()["verdict"])
