Add Pacta to Claude, Cursor or your own agent: one line, the first call, what is free and what costs

Pacta is an MCP server and a web API that tells an agent who can upgrade, pause or change a DeFi contract. Adding it takes one line. Most tools are free up to a daily limit and need no key; the rest are paid per call by the agent itself.

Changed 2026-11-28. The example answer on this page was read from the chain; its newest reading is from 2026-11-15.

Add it

Claude Code
claude mcp add --transport http pacta https://api.pacta.wtf/mcp
Cursor (mcp.json)
{
  "mcpServers": {
    "pacta": {
      "url": "https://api.pacta.wtf/mcp"
    }
  }
}

Any MCP client: the address is https://api.pacta.wtf/mcp, transport Streamable HTTP.

No MCP: the same over the web API, described at https://api.pacta.wtf/openapi.json.

The first call

Ask about the Stader Labs (ETHx) token: "Who controls 0xA35b1B31Ce002FBF2058D22F30f95D405200A15b on Ethereum?" You should get an answer like this one. Pacta's record holds: Stader Labs (ETHx): on its sampled timelocked controls, a decided change waits at least 7 days before it runs (read at Ethereum block #26,422,627 on 2026-11-15). The fewest signers needed on any sampled control is 3 of 6 (read at block #26,403,676 on 2026-11-13).

Two paid HTTP routes have no MCP tool: POST /v1/x402/calldata-sim ($0.25 a call) and POST /v1/x402/deep-scan ($9.00 a call).

How an agent pays

When a call goes over its free daily allowance, or calls a paid-only HTTP route, the API answers HTTP 402 Payment Required with the exact USDC price on Base and the receiving address (0x4348DF1BEFAffcbA248B5118B1b782B1B2bdEd14). An x402-capable agent signs a Base USDC transfer authorization locally, without creating an account or storing a card. It repeats the same HTTP request with the X-PAYMENT (v1) or PAYMENT-SIGNATURE (v2) header and receives the JSON answer.
