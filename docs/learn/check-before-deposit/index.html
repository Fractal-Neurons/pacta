Check a protocol before your agent deposits

Before an agent deposits, it should know three things about the contract it is about to trust: who can change it, what it depends on, and whether anything changed since the agent last looked. Each is one call. No API key or account is needed: who_controls is free for 100 calls a day, trace_dependencies is free with no daily limit, preflight is free for 50 calls a day (then $0.01 USDC per call on Base over x402), and wallet memory (remember and what_changed_since) is free on MCP and /v1/memory/* (100 calls a day per wallet, or $0.001 USDC per call with no daily cap on /v1/x402/*).

Changed 2026-11-28. The worked run on this page was read from the chain; its newest reading is from 2026-11-15.

The three checks, in order

  1. Who can change it: the MCP tool who_controls, or GET https://api.pacta.wtf/v1/check?chain=ethereum&address=0x…. Stop here if the answer surprises you.
  2. What it depends on: the MCP tool trace_dependencies, or GET https://api.pacta.wtf/v1/trace-dependencies?chain=ethereum&address=0x…. In the API description's own words: “What this vault, market or token depends on: its collateral assets, who can mint them, where its price comes from and who verifies its bridge. Each link cites a contract and a block.” One answer for the whole picture: the MCP tool pacta_check_preflight, or GET https://api.pacta.wtf/v1/check/preflight?chain=ethereum&address=0x…. In the tool's own words: “Block-pinned proxy, Safe signer/threshold, timelock delay, and docs-vs-chain comparison for the contract before an agent approves, deposits into or calls it.”
  3. What changed since last time: the MCP tool what_changed_since, or POST https://api.pacta.wtf/v1/memory/what-changed-since (given a list of contracts, a chain and a since_block, it needs no wallet), for an agent that saved its positions with remember (the MCP tool, or POST https://api.pacta.wtf/v1/memory/remember).

curl -s "https://api.pacta.wtf/v1/check?chain=ethereum&address=0xA35b1B31Ce002FBF2058D22F30f95D405200A15b"

A worked run

One protocol, Stader Labs (ETHx), four calls; the order is the order of the checks above. What follows each call is what Pacta's published records hold for it, with its block and date. A live call reads the chain now, so you should get an answer like this one, not necessarily the same.

  1. who_controls on the ETHx token contract 0xA35b1B31Ce002FBF2058D22F30f95D405200A15b, the contract a depositor receives. Pacta's record holds: Stader Labs (ETHx): on its sampled timelocked controls, a decided change waits at least 7 days before it runs (read at Ethereum block #26,422,627 on 2026-11-15). The fewest signers needed on any sampled control is 3 of 6 (read at block #26,403,676 on 2026-11-13).
  2. trace_dependencies on the same contract. The records on this site hold no dependency link for this contract, so no example answer is shown here.
  3. pacta_check_preflight on the Stader Manager Safe 0xAAfb31780e4b9c95Bc920e388f4925A874cd07AF, because that is the contract whose signer threshold Pacta's record reads. Pacta's record holds: At Ethereum block #26,403,676 on 2026-11-13 the record read this Safe's signer threshold: 3 of 6. The documents say: staderlabs.gitbook.io/ethereum states 'The Manager multisig is a 3-of-5 and is tasked with maintaining the protocol' and specifies a 7-day minimum delay on contract upgrades.
  4. what_changed_since on the ETHx contract since block 26,403,676, the block of that record. The answer depends on what happened on the chain after that block. The records on this site hold no later reading of this contract, so no example answer is shown here.

What it costs

What each check costs
Call (MCP tool, HTTP route)Free a day, per callerPrice after the free calls (USDC on Base, x402)
who_controls (GET /v1/check)100 a daynone: free only, the count resets at 00:00 UTC
trace_dependencies (GET /v1/trace-dependencies)no daily limit (60 a minute)$0.00
pacta_check_preflight (GET /v1/check/preflight)50 a day$0.01 a call
remember (POST /v1/memory/remember)100 a day per wallet (20 a minute)$0.001 a call on POST /v1/x402/remember (60 a minute, no daily cap)
what_changed_since (POST /v1/memory/what-changed-since)100 a day per wallet (20 a minute)$0.001 a call on POST /v1/x402/what-changed-since (60 a minute, no daily cap)
forget (POST /v1/memory/forget)free$0.00, always free

Where a route charges over x402, payment is per call in USDC on Base to 0x4348DF1BEFAffcbA248B5118B1b782B1B2bdEd14. A call that needs payment answers HTTP 402 with the price and the payment requirements; the agent signs the Base USDC authorization and repeats the HTTP call with X-PAYMENT (v1) or PAYMENT-SIGNATURE (v2). No account, no API key.

What it does not do

It does not decide for the agent. It returns facts and where they were read.
